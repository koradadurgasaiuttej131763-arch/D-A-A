Summary:
In this practical we successfully implemented BFS and DFS algorithms in Python for
traversing a graph. BFS uses a queue and visits the nodes level by level, while DFS
uses recursion and goes deep into one branch before moving to another branch. We
also calculated the execution time of both algorithms using time.perf_counter(). The time
complexity of both BFS and DFS is O(V + E) and the space complexity is O(V) when
the graph is represented using an adjacency list.


Conclusion:
In this practical we successfully performed BFS and DFS graph traversal algorithms.
Both algorithms are used to visit the nodes of a graph, but they follow different
approaches. BFS is useful for level-wise traversal and finding the shortest path in an
unweighted graph, whereas DFS is useful for deep traversal and problems like path
finding and cycle detection. We also learned how to calculate the execution time and
time complexity of the algorithms.
