Summary

Kruskal’s algorithm is used to find the Minimum Spanning Tree (MST) of a connected weighted graph. It first sorts all edges according to their weights and then selects the smallest edge one by one. An edge is added only if it does not create a cycle. The process continues until all vertices are connected with the minimum possible total cost.

Conclusion

Kruskal’s algorithm is a simple and useful method for finding a minimum spanning tree. It selects the lowest-cost edges while avoiding cycles. The algorithm is commonly used in network design, such as connecting computers, roads, or communication systems with minimum cost.
